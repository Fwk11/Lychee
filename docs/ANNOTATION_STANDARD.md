# Lychee 视频标注规范与评估标准

> 本规范定义 Lychee 视频标注的维度、取值、判定标准与复核规则。它是标注结果的唯一事实来源，与 `data/annotation_schema.json`（v2.0，工业级 RLHF 模板）严格对应。任何标注界面、导出脚本、Label Studio 模板都从这份 schema 生成，不在别处另写一份。

标注的目标不是"打几个标签"，而是为每一条镜头（shot）产出可直接用于训练奖励模型（reward model）的结构化资产：

1. 内容描述：这一镜拍了什么。
2. 技术 / 色彩分析：景别、运镜、构图、光线、色温等可枚举属性。
3. 多维评分向量：美学、情绪、数据价值等可比较的分数。
4. 合规判定：一票否决项。
5. 数据价值分：这条样本对训练集的贡献。

---

## 一、为什么按 RLHF 设计

RLHF 的训练数据是 **偏好对 (chosen, rejected)**：给同一个输入，哪个输出更好。因此我们的标准必须满足：

1. **可排序**：每个维度给出可比较的分数（1–5），而不是"是/否"，才能构成偏序。
2. **可分解**：一个总分没有意义，必须拆成多维向量，奖励模型才知道"好在哪"。
3. **可复核**：人工标注一致性（Cohen's Kappa）低 → 说明标准定义不清，要回炉修订。
4. **有闸门**：合规是一票否决，不进美学分——合规问题不该被"美"稀释。

---

## 二、维度分层

标注维度按五大块组织：

- **内容（A 块）**：画面里有什么、信息是否丰富、有无叙事。
- **技艺（B 块）**：景别、运镜、构图、色彩协调、光线质感、运动节奏——这是标注员手动确认或修订的主要部分。
- **情感（C 块）**：情绪基调、情绪强度、美学综合感受。
- **合规（G 块）**：闸门项，pass / warn / fail，不计入美学总分。
- **数据价值（V 块）**：技术质量、唯一性、多样性贡献、覆盖度、可标注性、许可合规。

### 维度总览（5 块 20 维）

```
内容 content      技艺 craft           情感 affect     合规 compliance   数据价值 data_value
─────────────────  ──────────────────  ─────────────  ────────────────  ──────────────────
A1 内容明确性      B1 景别              C1 情绪基调      G1 色情/裸露      V1 技术质量
A2 信息丰富度      B2 运镜              C2 情绪强度      G2 暴力/血腥      V2 唯一性(去重)
A3 叙事性          B3 构图              C3 美学综合      G3 违法/敏感      V3 多样性贡献
                   B4 色彩协调          (D7)           G4 水印/贴片      V4 覆盖度(补空白)
                   B5 光线质感                          G5 可辨识人脸    V5 可标注性
                   B6 运动节奏                                          V6 许可合规
```

*G 块为闸门（pass/warn/fail，不计入总分）；其余 17 维各 1–5 分，作为 reward 特征向量。*

## 三、时间轴标签（可枚举属性）

时间轴标签是每镜必填的结构化属性，取值来自 schema 的 `timeline_labels`。标注员在界面勾选，导出时归一化为时间区间。

| 维度 | 取值示例 | 判定要点 |
| --- | --- | --- |
| 景别 scale | 大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 | 以人物占画幅比例或主体与环境关系为准，不看绝对距离 |
| 运镜 camera | 固定 / 推 / 拉 / 摇 / 移 / 跟拍 / 航拍 / 手持 … | 看相对运动，静止主体+移动机位也算运动 |
| 构图 composition | 三分法 / 对称 / 引导线 / 框架式 / 留白 / 对角线 … | 主体在画面中的组织方式，可多选 |
| 角度 angle | 平视 / 俯拍 / 仰拍 / 荷兰角 … | 机位与主体视线关系 |
| 镜头/景深 lens | 广角 / 标准 / 长焦 / 鱼眼 / 微距 / 浅景深 / 深景深 | — |
| 曝光 exposure | 正常 / 过曝 / 欠曝 | — |
| 光位 light_position | 顺光 / 侧光 / 逆光 / 顶光 / 底光 / 伦勃朗光 | — |
| 光质 light_quality | 硬光 / 柔光 | — |
| 光源 light_source | 自然光 / 人造光 / 混合光 | — |
| 影调 tone | 高调 / 低调 / 中间调 | — |
| 色温 color_temp | 暖调 / 冷调 / 中性 | — |
| 饱和度 saturation | 低饱和 / 正常 / 高饱和 | — |
| 配色 color_scheme | 互补色 / 类似色 / 单色 / 撞色 / 莫兰迪 | — |
| 人物 people | 单人 / 多人 / 群像 / 无人物 | 决定后续一致性校验范围 |

## 四、内容与叙事（A 块）

### A1 内容明确性 content_clarity —— 画面里"是什么"能否一眼认出

| 分 | 定义 | 反例 |
|---|---|---|
| 5 | 主体、场景、动作全部清晰可辨 | — |
| 3 | 能认出大类，细节模糊 | 背光剪影 |
| 1 | 过曝/过暗/严重模糊，无法辨识 | 一片黑 |

*机器线索：VLM caption 是否非空且具体；模糊度(Laplacian)、亮度是否越界。*

### A2 信息丰富度 information_richness —— 画面承载多少有效语义

5 = 主体+环境+道具+动作多层信息；1 = 纯色/空镜无信息。

*机器线索：VLM caption 长度/具体实体数；色彩方差；边缘密度。*

### A3 叙事性 narrative —— 是否有"正在发生的事"或情绪推进

5 = 明确动作/事件/关系；3 = 静态但有氛围；1 = 纯空镜无叙事。

## 五、技艺（B 块）

### B1 景别 shot_scale（大远景/远景/中景/近景/特写/无主体）

*机器线索：VLM 主体检测 + 主体占画幅比；人物检测器。*

### B2 运镜 camera_move（固定/摇/推拉/跟随/手持/航拍）

**机器实现 = 光流法**（不是 VLM）：对镜头内采样帧做稠密/稀疏光流，统计运动场主方向与稳定性：
- 全图统一向右 → 摇(pan)；向中心收缩/外扩 → 推拉(zoom)；
- 主体稳定背景流动 → 跟随(track)；高频小幅抖动 → 手持；大范围高空位移 → 航拍。

### B3 构图 composition（三分法/中心对称/留白/对角线/框架式）

*机器线索：主体位置相对三分线、对称轴、负空间占比。*

### B4 色彩协调 color_harmony —— 不是越饱和越好，看协调

| 分 | 定义 |
|---|---|
| 5 | 主色≤3 且色相和谐（同类/互补），明暗有层次 |
| 3 | 色彩普通，无明显冲突 |
| 1 | 色彩杂乱刺眼 / 一片灰黑 |

*机器线索：主色数量与色相间距离、饱和度分布、冷暖一致性、对比度。*

### B5 光线质感 lighting —— 曝光正确 + 明暗有质感

*机器线索：亮度均值是否越界(欠曝/过曝)、亮度直方图层次、高光/阴影保留。*

### B6 运动节奏 motion_rhythm —— 镜头内运动幅度与剪辑节奏是否服务内容

*机器线索：光流运动幅值均值/方差；镜头时长与切换频率。*

## 六、情感与审美（C 块）

- **C1 情绪基调 mood**（宁静/活力/伤感/浪漫/紧张/治愈）— VLM+色彩冷暖辅助
- **C2 情绪强度 emotional_intensity**：1 平淡 ↔ 5 强烈（与内容、色彩、运动联合判断）
- **C3 美学综合 aesthetic_score**（1–5 整数，**人工双标**）——综合主观审美，作为奖励模型的主要回归目标之一

---

## 七、评分锚点（1–10）

统一用 1–10 锚点：

> 1 = 渣片/不可用，3 = 业余，5 = 合格，7 = 专业成片感，9 = 大师级/惊艳，10 = 完美。

导出到 Label Studio 时，1–5 区间的值会线性映射到 1–10，保证全数据集尺度一致。常见错误：把"我喜欢"当成高分依据——评分应基于画面客观完成度，而非个人偏好。

---

## 八、导演级理解（本地视觉模型自动预标注）

系统用本地视觉模型（qwen2.5vl:3b）对每镜中帧做一次理解，自动填充以下字段，作为人工复核的起点：

- `content_caption`：画面内容描述。
- `shot_scale` / `composition`：景别与构图（对照上述枚举）。
- `mood`：情绪基调。
- `aesthetic_score`：1–10 美学评分。

预标注可能出错（尤其黑场、过曝、快速运动帧），因此**所有自动字段都允许人工覆盖**。复核时优先检查：景别是否跳档、构图是否识别成"无明显特征"、情绪是否与画面冲突。

---

## 九、合规闸门（G 块）

合规是闸门，不进美学分。合规问题不该被"美"稀释。

| 维 | 判定 | 严重度 |
|---|---|---|
| G1 色情/裸露 | 关键词表 + 暗红像素启发式 | fail>0.7 / warn>0.4 |
| G2 暴力/血腥 | 关键词 + 暗红像素占比（有亮度门控排除夕阳） | fail/warn |
| G3 违法/敏感 | 关键词表扫描 VLM 描述 | fail |
| G4 水印/贴片/广告 | 边角 Canny 边缘密度（静态水印让多数角变忙） | warn（污染训练数据，通常降权或剔除） |
| G5 可辨识人脸 | OpenCV Haar 级联人脸检测 | warn（肖像权风险，数据需脱敏或授权） |

> G1–G3 为 fail 时整条剔除，不进数据集、不进 RLHF；G4–G5 为 warn，降权或标注后人工裁。任意一项命中即标记为需复核或阻断。含可辨识人脸的素材在对外分发前要单独确认授权。

## 十、数据价值（V 块）

数据价值决定一条样本是否值得进入训练集。数据价值与美学**正交**：一条很美的视频若与数据集重复(V2低)，训练价值仍低；一条普通视频若是稀缺的"航拍夜景"(V4高)，训练价值很高。这正是数据运营的判断力。

| 维 | 含义 | 机器线索 |
|---|---|---|
| V1 技术质量 | 分辨率/清晰度/无压缩伪影 | 分辨率、模糊度、码率 |
| V2 唯一性 | 与数据集内其他样本的重复度 | pHash 汉明距离（越小越重复） |
| V3 多样性贡献 | 是否带来新场景/新景别/新色彩 | 与已有样本特征距离 |
| V4 覆盖度 | 是否填补稀缺类别空白 | 数据集类别分布反向权重 |
| V5 可标注性 | 单镜头、边界清晰、无复杂转场 | 镜头数、切分置信度 |
| V6 许可合规 | CC0/可商用/来源可追溯 | 来源元数据 |

## 十一、评分量表与权重

美学总分（供参考，非 RLHF 直接用）= Σ(wᵢ × scoreᵢ)，建议权重：

| 维度 | A1 | A2 | A3 | B1 | B2 | B3 | B4 | B5 | B6 | C1 | C2 | C3 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 权重 | .08 | .07 | .05 | .06 | .08 | .08 | .10 | .08 | .06 | .06 | .06 | .22 |

*RLHF 不用这个加总分，而用 17 维向量直接做 reward 特征。*

---

## 十二、RLHF 集成

**奖励模型特征向量**（每条 shot）：

```
reward_features = [A1,A2,A3, B1..B6, C1,C2,C3, V1..V6]   # 17 维, 各 1-5
```

**偏好对生成**：
- 在同一主题/景别/色彩类别内，取高分 shot 作 chosen、低分作 rejected。
- 格式：

```json
{
  "prompt": "city street at night, medium shot, cool tone",
  "chosen":   {"video_id": "...", "shot_id": "s1", "reward_features": {...}, "aesthetic_score": 5},
  "rejected": {"video_id": "...", "shot_id": "s2", "reward_features": {...}, "aesthetic_score": 2},
  "margin": 3
}
```

**闭环**：
1. Agent(VLM+光流+OpenCV) 预标 17 维 → 2. 人工双标复核 C3 + 抽检 A/B 维
→ 3. Cohen's Kappa 算一致性，<0.6 的维度回炉修订定义 → 4. 导出偏好对训 reward model。

---

## 十三、复核与一致性

- 同一数据集的所有样本在 Label Studio 打开应是同一套标签模板（模板按数据集粒度生成，不按单视频裁剪）。
- 标注员之间的一致性用 Cohen's Kappa 监控；某个维度 Kappa 持续偏低，说明枚举定义或判定标准不清，需回炉修订本规范，而不是迁就标注员。
- 跨章人物一致性由小说分镜的一致性守门单独处理（见系统 README 的小说模块），不在视频标注范围内。

---

## 十四、交付格式

标注结果可导出三种格式，用途不同：

- **JSON**：完整结构化，含全部时间轴标签、评分、合规、数据价值，用于系统内部与奖励模型特征提取。
- **CSV**：每条镜头一行，便于在表格工具或脚本里做统计与筛选。
- **Label Studio**：生成项目配置 + 预填标注，供人工复核与 pairwise 偏好对构造。

需要新增维度时，先改 `data/annotation_schema.json`，再重新生成模板，不要手写改导出代码。
